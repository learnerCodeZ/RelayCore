代码基线：`c8e6b7f3081127d74887504b5dc68fb4753ecf35`。

这些脚本用于证明问题，不会修改产品源码、真实任务或真实 DSH 注册表，不调用真实模型。任务和文件夹具位于系统临时目录，结束后清理。脚本中直接写 SQLite 只用于构造跳过模型的测试夹具，不是生产修复方法。

在项目根目录执行（需要 Node.js 24.15.x 和现有依赖）：

```powershell
node docs/release-review-2026-11-08/workflow-repro.mjs .
node docs/release-review-2026-11-08/security-repro.mjs .
```

- `workflow-repro.mjs`：实际并行整合；回滚中断磁盘现场模拟；生产执行入口的暂停恢复。
- `security-repro.mjs`：临时 DSH 索引的受控交错覆盖；环境变量关闭被配置文件覆盖。
- `results.json`：此次审查的机器可读摘要。

并行整合出现次数受调度影响，不能作为生产概率；没有碰到某个竞争窗口也不能证明缺陷已消除。回滚案例构造的是中断后现场，不是真实断电试验。修复完成后应将场景转换为正式回归断言，不能只依赖人工观察输出。
